# ARCANA — 메인 메뉴 페이지 확장판

압축을 풀고 index.html을 Chrome 또는 Edge에서 열면 됩니다. 설치나 빌드가 필요 없습니다.
폴더 전체를 함께 이동해 주세요. VS Code Live Server에서도 실행할 수 있습니다.

## 페이지
- index.html: 기존 메인페이지
- about.html: 게임 소개, 세계관, 연대기, 아트
- news.html: 새소식, 분류 필터, 주요 안내
- monsters.html: 7종 몬스터 도감, 전체 카드 목록, 추천 조합
- guide.html: 전투 가이드, 카드 읽는 법, 턴 흐름, FAQ
- events.html: 시작 카드 추천, 7가지 미션 체크리스트

모든 페이지에 공통 헤더와 링크가 있으며, 현재 메뉴에 골드 표시가 적용됩니다.
로고를 누르면 index.html로 돌아갑니다. 하위 서브메뉴 페이지는 만들지 않았습니다.

## 공통 파일
- style.css / script.js: 기존 공통 디자인 및 동작
- pages.css / pages.js: 개별 페이지 디자인, 카드 목록, 미션 기능
- images/monsters-refined.png: 제공 원화를 참고해 새로 제작한 몬스터 아틀라스(4열 2행)
- images/hero-keyart.png: 메인 일러스트
- images/monster-source.jpg: 제공된 원본 보존; 전장 예시에서 사용
- icons/: SVG 로고와 능력 아이콘

## 편집
텍스트는 해당 HTML에서 수정하세요. 몬스터 데이터는 script.js의 monsters 배열에 있습니다.
몬스터 아틀라스는 위쪽 왼쪽부터 세라피온, 씨 슬러그, 아이언혼, 그리폰,
아래쪽 왼쪽부터 베르단트, 드라카리스, 솔라리스, 수정 순서입니다.
이미지는 CSS background-size:400% 200%로 한 칸씩 표시합니다.

로그인은 체험용이며 실제 계정 인증·서버 통신·카드 대전은 없습니다.
닉네임은 현재 탭에, 이벤트 체크 상태는 브라우저 localStorage에만 저장합니다.
세계관, 능력치, 시즌과 이벤트 내용은 창작 설정입니다.

## 검수 범위
파일 간 링크, HTML ID 중복, JS 문법 및 페이지별 초기화 동작 검사.
이번 확장판은 미리보기 브라우저 접근 제한으로 최종 시각 검수를 완료하지 못했습니다.

## 이미지 및 확대 업데이트
메인·가이드의 게임 화면을 gameplay-table.png로 교체했습니다.
‘신화를 소환하다’의 큰 몬스터 이미지 또는 우측 아래 돋보기를 누르면 확대됩니다.
키보드 Enter/Space도 지원합니다. 닫기 버튼, Escape 또는 바깥 영역 클릭으로 닫을 수 있습니다.
게임 화면도 누르면 확대됩니다.
archive-room.png는 소개·새소식·세계관에, strategy-desk.png는 가이드·이벤트·하단 배경에 사용합니다.

## 이벤트 확장
게임 소개는 상단 비주얼 한 장 다음에 텍스트 중심 소개가 이어집니다.
이벤트 목록은 배너 2개씩 1·2페이지로 나뉩니다. 아래 숫자를 누르면 전환되고 URL에 페이지가 유지됩니다.
배너 클릭 시 event-detail.html에서 상세 내용과 참여 안내를 볼 수 있습니다.
상세 페이지의 목록 버튼은 원래 목록 페이지로 돌아갑니다.
새 이미지: images/event-cards.png, images/event-chest.png.

## 정렬 및 이벤트 배너 수정
게임 소개 본문은 중앙 정렬과 전용 중앙 여백 배경을 사용합니다.
첫 서약 추천 섹션은 도감의 몬스터 선택과 일곱 존재의 기록 사이로 이동했습니다.
이벤트 배너는 한 줄에 하나씩 가로형이며, 1페이지(카드·상자)와 2페이지(테이블·서재)의 이미지가 다릅니다.
균열 너머의 빛 카드는 호버 시 골드 테두리를 표시합니다.
